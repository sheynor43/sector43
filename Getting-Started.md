# 🚀 Как начать играть на Sector 43

## 1. Подключение

Открой Minecraft → Multiplayer → Add Server

Введи IP сервера, который вам выдадут после одобрения заявки.

Подключитесь и примите скачивание ресурс пака. Он нужен для корректного отображения таба и префиксов.

---

## 2. Моды для взаимодействия с игроками

На данный момент на сервере поддерживается взаимодействие между игроками с помощью следующих модов:
- Patpat
- Plasma Voice (В будущем)
